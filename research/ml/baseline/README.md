# Phase 5 Baseline ML Experiment Output Directory

This directory contains structured execution outputs for Phase 5 baseline classifiers:

- `results.json`: Complete metrics, cross-validation scores, and per-class performance.
- `metrics.csv`: Tabular evaluation metrics summary.
- `model_config.json`: Hyperparameters, seeds, and dataset split configurations.
- `confusion_matrices/`: Per-model 4x4 matrix JSON outputs.
